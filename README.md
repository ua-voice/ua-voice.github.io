# ua-voice.github.io

Одна сторінка підтримки для всіх товарів і магазинів.

Приклад адреси:

```text
https://ua-voice.github.io/?qr=inhaler_r1
```

## Ідентифікатори

- `product_id` — постійний внутрішній код товару;
- `store_id` — код магазину;
- `qr_id` — код конкретного QR-маршруту товар + магазин.

Поточний резервний маршрут зберігається у `catalog.js`. Основні дані великого
каталогу завантажуються з Google Таблиці через Google Apps Script.

Фото, PDF та інші файли вказуйте відносними шляхами без домену. Завдяки цьому
підключення власного домену не потребуватиме зміни каталогу.

Посилання на відгук зберігається у відповідному рядку аркуша
`QR-маршрути`, тому один товар може мати різні посилання для різних магазинів.

Якщо у товару не заповнений `Шлях до фото`, сторінка автоматично покаже
лагідний фон відповідно до поточної пори року.
