# UA Voice QR Site v4

Сайт використовує один актуальний знімок `catalog.json`, який Apps Script
автоматично формує з Google Таблиці.

## Файли товарів

Фото:

```text
photos/АРТИКУЛ.webp
```

PDF-інструкція:

```text
instructions/АРТИКУЛ.pdf
```

Наприклад:

```text
photos/inhaler.webp
instructions/inhaler.pdf
```

Назва файлу повинна точно відповідати значенню `Код товару` в таблиці,
включно з дефісами, цифрами та регістром літер.

## Важливо

- `catalog.json` оновлюється автоматично — вручну його не редагуйте.
- Старий `catalog.js` більше не використовується.
- Контакти редагуються в Google Таблиці.
- `contacts.js` містить лише аварійний телефон на випадок помилки.
- Відео зберігайте на YouTube, а в таблиці вставляйте посилання.
- Після зміни таблиці оновлення сайту може зайняти приблизно 1–4 хвилини.

QR-посилання:

```text
https://ua-voice.github.io/?qr=КОД_QR
```
